# Prime Solutions website

Everything for the Prime Solutions website project in one place.

| Folder | What is in it |
|---|---|
| `site/` | The website project (`site.json`, `build.py`, `demos.py`, `src/`, and the finished `dist/` folder that gets uploaded). It holds all three levels from one set of files: Premium (`index.html`), Pro (`pro.html`) and Standard (`standard.html`), plus the privacy page, built from `site/legal/privacy-policy.md`. `site/README.md` explains how to build and change it |
| `assets/` | `hero-test.jpg`, a test hero banner (dark green, space on the left for a headline) |
| `legal/` | `privacy-policy-draft.md`, a draft privacy policy with placeholders to fill in. Not legal advice. |
| `review/` | `mobile-review.md` and screenshots from the phone and desktop review |

This repository is public for now. Do not add passwords, keys, client details or prices that should stay private.
